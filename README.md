# StudySpace – Landing Page

StudySpace is a modern and responsive landing page designed for a student-focused learning platform.

## Files

### index.html

Contains the structure and content of the StudySpace landing page, including:

- Navigation bar
- Hero section
- Call-to-action buttons
- Features section
- About section
- Contact section
- Footer

### style.css

Contains the styling and responsive design for the website, including:

- Color theme
- Typography
- Layout and spacing
- Navigation styling
- Cards
- Buttons
- Responsive design for mobile and desktop screens

## Technologies Used

- HTML5
- CSS3

## Features

- Fixed navigation bar
- Responsive layout
- Modern student-friendly design
- Multiple content sections
- Call-to-action buttons
- Social media links in the footer
